# DECISIONS

1. **One shared engine, three brands.** Static storefronts generated by one Python/Jinja2 builder from one catalogue; one Supabase backend. Near-zero hosting cost, no per-store servers.
2. **Deterministic product factory, no AI at run time.** Products come from code templates (reportlab/xlsxwriter/python-docx) + structured specs. Rebuilds are idempotent (spec + code hash checkpoint). AI was used once to author specs/content.
3. **Private IP stays out of the public repo.** The repo `mlinjana/mlinjana` is public, so `commerce/factory/` (generators) and `commerce/build/` (deliverables) are gitignored. Generators are backed up to the private `backups` bucket; files live in the private `products` bucket and are served only via 2-minute signed URLs after a verified payment.
4. **PayFast first.** SA-native, ZAR, public sandbox so checkout can be tested without your credentials. Paystack's published card rates are lower — a second adapter is a good next step.
5. **Order is paid only on a verified ITN:** signature (MD5 + passphrase) ✓, PayFast server validation = `VALID` ✓, merchant & mode match ✓, amount matches ✓. Idempotent `pending → paid` update.
6. **Vercel Hobby for staging only.** Its terms prohibit commercial use; live sales need Cloudflare Pages (free) or Vercel Pro (paid).
7. **Supabase pg_cron for scheduling** (runs without your computer or a Claude session). Jobs are capped per day; 5 consecutive errors or a budget breach flips a kill switch that pauses automation and checkout.
8. **Prices are evidence-based (2026-10-28) but untested by real sales.** `engine/pricing.py` places each product inside the typical band of observed competitor list prices (Etsy/Gumroad/Payhip/Flevy) — mid-market because the shops have no reviews; 52 of 60 benchmarked, 8 estimated by analogy (flagged). Own-store ZAR = USD × 16.4 × 0.75, rounded to R..9 (min R39). Full table with evidence: `research/pricing.csv`.
9. **Admin auth = owner key** (SHA-256 hash stored server-side, constant-time compare). Supabase Auth email links would need dashboard config not available to the connector.
10. **No cookies / no IP logging** in analytics: page path, product, referrer host only.
11. **Brand names:** Plainday Studio, Bizwright, Abacus Lane (domains available at check time; no conflicting brand found in web search; formal trademark search still required).
12. **Sandbox signing.** PayFast's shared sandbox merchant (10000100) rejected signatures made with the passphrase published in third-party docs, but accepts unsigned forms. In sandbox mode without a configured passphrase the form is unsigned and the ITN is trusted only after PayFast server validation (`VALID`) + merchant + amount checks. **Live mode always requires the signature** with your passphrase.
13. **Supabase client imported via `npm:` specifier** — the bundler timed out fetching from JSR twice.
14. **Deploy via Git integration, not file upload** — uploading the site through Claude would cost ~760 KB of text per update; Git deploys cost nothing.
