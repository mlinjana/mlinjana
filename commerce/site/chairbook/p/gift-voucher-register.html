What's inside

  • Track gift vouchers sold, values, expiry dates, redemptions and balances.
  • 'Vouchers' log (300 rows): Voucher no., Sold on, Bought by, Value, Expires, Redeemed, Balance
  • Key numbers: Vouchers sold, Outstanding balance
  • Editable drop-down lists, protected formulas, example rows to show how it works

How to use it

  1. Read through the column headings so you know what each one records.
  2. Record entries on 'Vouchers' — one row each. Yellow cells are inputs; white cells calculate.
  3. Open 'Summary' to see totals, key numbers and the chart update automatically.
  4. Delete the example rows before you start.
