Item details
  • Task list with owners, dates, status, priority and progress bars
  • Automatic Gantt timeline with today marker
  • Dashboard with overdue and blocked counts
  • RACI matrix and scored risk register
How to use it
  1. Enter the project start date on 'Timeline' (cell B3).
  2. List tasks on 'Tasks' with owner, start, due date, status, priority and % complete.
  3. 'Timeline' draws a 26-week Gantt chart; overdue tasks are highlighted on 'Tasks'.
  4. 'Dashboard' summarises progress; use 'RACI' and 'Risks' for responsibilities and risk scoring.
Files and compatibility

Microsoft Excel 2010+, Excel for the web, Google Sheets and LibreOffice Calc. No macros.
