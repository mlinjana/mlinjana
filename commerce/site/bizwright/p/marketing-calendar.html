Item details
  • Campaign list with channel, dates, budget, owner and KPI
  • Automatic 52-week calendar (live campaigns highlighted)
  • Budget vs actual by channel with chart
  • Editable channel and status lists
How to use it
  1. Set the calendar start date on 'Calendar' (cell B3) — usually the first Monday of your year.
  2. List campaigns on 'Campaigns' with channel, start and end dates, budget and owner.
  3. The 'Calendar' sheet shades each campaign's active weeks automatically (52 weeks).
  4. 'Budget' summarises planned and actual spend by channel and month.
Files and compatibility

Microsoft Excel 2010+, Excel for the web, Google Sheets and LibreOffice Calc. No macros.
