What's inside

  • Track subscribers, open rates and clicks for every issue of your newsletter.
  • 'Issues' log (300 rows): Sent, Issue title, Subscribers, New, Unsubscribes, Open rate, Click rate
  • Key numbers: New subscribers, Average open rate
  • Editable drop-down lists, protected formulas, example rows to show how it works

How to use it

  1. Read through the column headings so you know what each one records.
  2. Record entries on 'Issues' — one row each. Yellow cells are inputs; white cells calculate.
  3. Open 'Summary' to see totals, key numbers and the chart update automatically.
  4. Delete the example rows before you start.
