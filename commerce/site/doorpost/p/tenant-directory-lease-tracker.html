What's inside

  • Keep tenant contacts, lease dates, deposits and renewal reminders in one place.
  • 'Tenants' log (300 rows): Property, Tenant, Phone, Lease start, Lease end, Rent, Deposit held…
  • Automatic count by renewal decision, with chart
  • Key numbers: Monthly rent, Deposits held
  • Editable drop-down lists, protected formulas, example rows to show how it works

How to use it

  1. Edit the drop-down options on the 'Lists' sheet to match your situation.
  2. Record entries on 'Tenants' — one row each. Yellow cells are inputs; white cells calculate.
  3. Open 'Summary' to see totals, key numbers and the chart update automatically.
  4. Delete the example rows before you start.

Works with

Microsoft Excel 2010+, Excel for the web, Google Sheets and LibreOffice Calc. No macros.
