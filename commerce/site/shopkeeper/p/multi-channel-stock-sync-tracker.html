Item details
  • Compare real stock with quantities listed on each channel and flag overselling risk.
  • 'Stock' log (300 rows): SKU, Product, Actual stock, Listed on website, Listed on Etsy, Listed on Amazon, Highest listed…
  • Key numbers: SKUs at risk, Units in stock
  • Editable drop-down lists, protected formulas, example rows to show how it works
How to use it
  1. Read through the column headings so you know what each one records.
  2. Record entries on 'Stock' — one row each. Yellow cells are inputs; white cells calculate.
  3. Open 'Summary' to see totals, key numbers and the chart update automatically.
  4. Delete the example rows before you start.
Files and compatibility

Microsoft Excel 2010+, Excel for the web, Google Sheets and LibreOffice Calc. No macros.
