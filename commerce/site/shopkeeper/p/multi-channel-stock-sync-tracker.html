How to use it

  1. Read through the column headings so you know what each one records.
  2. Record entries on 'Stock' — one row each. Yellow cells are inputs; white cells calculate.
  3. Open 'Summary' to see totals, key numbers and the chart update automatically.
  4. Delete the example rows before you start.
