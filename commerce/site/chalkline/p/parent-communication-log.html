How to use it

  1. Edit the drop-down options on the 'Lists' sheet to match your situation.
  2. Record entries on 'Log' — one row each. Yellow cells are inputs; white cells calculate.
  3. Open 'Summary' to see totals, key numbers and the chart update automatically.
  4. The first rows are a worked example, so you can see how a filled-in tracker and its summary look. When you're ready, select the example cells in the yellow input columns and press Delete (clear the contents; don't delete whole rows, so the calculations keep working).
