Item details
  • Automatic ranking and cumulative % — no sorting
  • Adjustable A/B thresholds
  • Item and value share per class
  • Chart
How to use it
  1. Paste your items on 'Items': SKU, description, annual usage (units) and unit cost.
  2. Set the class thresholds on 'Summary' (defaults: A = top 80% of value, B = next 15%, C = last 5%).
  3. Each item is ranked by annual value and classified automatically — no sorting needed.
Files and compatibility

Microsoft Excel 2010+, Excel for the web, Google Sheets and LibreOffice Calc. No macros.
